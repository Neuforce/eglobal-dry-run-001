Todas las fases se leen igual: entradas, skill y qué hace el LLM, gate humano, salida. La Fase 0 es la idea de Aníbal: el primer entregable de un spike es su propio proceso de validación. Elegimos un proceso chico y crítico, y decidimos si empezamos por los docs y buscamos en el código, o al revés. Docs → código encuentra drift rápido; código → docs encuentra lógica no documentada.
